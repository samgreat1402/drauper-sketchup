# Unified Vertical Studio — v4.1.31

## Scope

- One primary `UI::HtmlDialog` containing the complete Draupr interface.
- Vertical workspace rail for Create, Edit, Modify, Materials, Library, and Project.
- All existing parameter fields, galleries, modifiers, reports, and action controls retained.
- Collapsible icon-only workspace rail persisted locally in the dialog.
- Responsive single-column fields at narrow widths and two-column fields when expanded.
- English/Persian and RTL support retained.

## Native acceptance

1. Install the RBZ and restart SketchUp.
2. Click the Draupr toolbar icon; confirm the unified Studio opens near 480 × 840.
3. Visit all six workspace tabs and confirm every existing control remains available.
4. Create and edit at least one object from each category.
5. Exercise Modify, Materials, Library, Levels, Reports, and Model Health.
6. Collapse the workspace rail, close Studio, reopen it, and confirm the rail state persists.
7. Resize to 390 px and above 560 px; verify field grids adapt without clipped controls.
8. Switch EN/FA and verify rail selection, RTL layout, dialogs, and sticky action controls.
9. Confirm Esc, native Undo/Redo, selection watching, and active-tool status remain functional.
