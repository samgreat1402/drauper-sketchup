# Function-Specific Icons — v4.1.33

## Visual language

- Create icons depict the generated architectural object, not a generic command.
- Modify icons diagram the source geometry, target boundary, and operation direction.
- All icons use a 24 × 24 view box, rounded joins/caps, and consistent 1.55 px strokes.
- Text remains available through translated hover/focus labels and accessible names.

## Review checklist

1. Review every Create category at 390, 480, and 610 px.
2. Verify each icon remains distinguishable at 100%, 125%, 150%, and 200% Windows scaling.
3. Review all 18 Modify icons without reading their tooltips, then confirm the tooltip wording.
4. Verify active, hover, disabled, destructive, light, and dark states.
5. Verify English/Persian labels, RTL positioning, and keyboard focus.
